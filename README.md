#  Networking Projects

A collection of networking projects and Cisco Packet Tracer labs focused on practical network design, configuration, and troubleshooting.

## 🛠️ Topics Covered

- Cisco Packet Tracer
- IP Addressing
- Routing & Switching
- DHCP & DNS
- VLANs
- OSPF
- RIP
- TCP/IP
- Subnetting
- Network Troubleshooting

## 📂 Projects

Each folder contains an individual networking project along with its Packet Tracer file and documentation.

## 🎯 Purpose

This repository contains hands-on networking practice and lab projects developed to strengthen my understanding of network configuration, connectivity, and troubleshooting.
