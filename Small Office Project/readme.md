# 🏢 Small Office Network

## 📌 Overview

A basic Small Office Network designed and configured using Cisco Packet Tracer.

The project demonstrates fundamental networking concepts including device configuration, IP addressing, basic router and switch configuration, and connectivity testing between end devices.

## 🖥️ Network Topology

The network consists of:

- 1 Router
- 1 Switch
- 4 PCs

## ⚙️ Configuration

The following configurations were implemented:

- Configured the router hostname.
- Configured router passwords for basic access security.
- Assigned IP addresses to the network devices.
- Configured the PCs with appropriate IP addresses and default gateway.
- Connected the devices through the switch.
- Verified connectivity between the PCs using `ping`.

## 🧪 Connectivity Testing

Connectivity was verified using the `ping` command between the connected PCs.

Example:

```bash
ping <destination-IP>
```

Successful ping responses confirmed that the devices were properly configured and could communicate with each other.

- Basic Switch Configuration
- IP Addressing
- Ping / Connectivity Testing
